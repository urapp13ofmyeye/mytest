# 📚 시험 공부 플래너

시험 기간의 일정·공부 계획·체크리스트를 한 화면에서 관리하는 개인용 플래너입니다.
폰과 PC에서 모두 쓸 수 있고, 설치나 로그인 없이 브라우저에서 바로 열립니다.

**화면 코드와 학기 데이터가 분리되어 있어서, `data/semester.js` 파일 하나만 바꾸면 다른 학기나 다른 사람도 그대로 쓸 수 있습니다.**

## 주요 기능

| 탭 | 할 수 있는 것 |
|---|---|
| ☀️ **오늘** | 시험별 D-day, 시간대별 하루 일정(수업·알바·식사·공부 블록), 할 일 체크와 추가 |
| 📅 **달력** | 월요일 시작 주간 달력, 과목 색으로 구분된 공부 블록, 목록 보기 전환 |
| 📖 **과목** | 전체 개요, 과목별 시험 정보·단계별 전략·진행도·메모 |
| ✅ **체크리스트** | 카테고리별 체크리스트, 카테고리와 항목 직접 추가 |
| ⚙️ **기타** | 교시 기준 고정 시간표, 자격증 D-day, 백업 |

### 공부를 도와주는 기능

- **밀린 일 이월** — 못 끝낸 블록을 모아 보여주고, 오늘·내일로 옮기거나 버릴 수 있습니다.
- **지금 할 일 + 뽀모도로** — 지금 할 블록 하나만 크게 보여주고 25분 타이머로 실제 공부 시간을 기록합니다.
- **AI 프롬프트 복사** — 과목별 시험 유형에 맞춘 퀴즈 프롬프트를 복사해 자료와 함께 붙여넣습니다.
- **암기 카드** — 약어·용어를 넣어두고 답을 가린 채 셀프 테스트합니다. 여러 장을 한 번에 붙여넣을 수 있습니다.
- **확인 필요 표시** — 아직 모르는 시험 범위·유형을 노란색으로 모아 보여줍니다.
- **필수 / 여유 블록** — 밀리면 버려도 되는 블록을 점선으로 구분합니다.

## 폴더 구조

```
index.html                  화면 뼈대
css/style.css               스타일 (다크 모드 포함)
data/
  semester.js               ★ 학기 데이터 — 이 파일만 고치면 됩니다
  semester.example.js       새 학기용 빈 틀
js/
  store.js                  저장 상태, 날짜·시간 도우미, 공부 블록 계산
  app.js                    탭 전환, 화면 그리기, 클릭·입력 처리
  components/
    now.js                  밀린 일 상자, 지금 할 일 카드, 뽀모도로 타이머
    today.js                오늘 탭
    calendar.js             달력 탭
    subjects.js             과목 탭, AI 프롬프트, 암기 카드
    checklist.js            체크리스트 탭
    more.js                 기타 탭 (시간표, 자격증, 백업)
배포가이드.md                 깃허브 업로드와 Vercel 배포 순서
```

외부 라이브러리와 빌드 과정이 없습니다. HTML·CSS·JavaScript만 사용합니다.

## 새 학기에 쓰기 (또는 내 것으로 만들기)

1. `data/semester.example.js`를 복사해서 `data/semester.js`에 덮어씁니다.
2. 아래 항목을 내 일정으로 바꿉니다.
3. 브라우저에서 `index.html`을 새로고침합니다.

| 항목 | 내용 |
|---|---|
| `CONFIG` | 제목, 아이콘, 저장 키 |
| `YEAR`, `SEM_START` | 연도, 개강일(1주차 첫날) |
| `SUBJ` | 과목 이름과 색 |
| `WD`, `P_START`, `P_END` | 요일별 고정 시간표, 교시 시각 |
| `MEAL` | 요일별 식사·휴식 시간 |
| `EVENTS` | 시험과 마감 일정 |
| `PLAN` | 날짜별 공부 블록 |
| `INFO` | 과목별 시험 정보와 전략 |
| `SEED_LISTS` | 체크리스트 초기 항목 |
| `PROMPTS` | 과목별 AI 프롬프트 |
| `CERTS`, `TIPS` | 자격증 D-day(없으면 `null`), 안내 문구 |

### 작성 규칙

- 날짜는 `'MM-DD'`, 시간은 `'HH:MM'` 형식입니다.
- 공부 블록은 `[시작, 끝, 과목, 할 일, 여유 여부]` 순서입니다.

```js
'10-13': [['10:00', '12:00', 'hn', '발표자료 PPT·대본 완성'],
          ['19:00', '20:30', 'hn', 'PPT·대본 마무리', 1]],   // 끝의 1 = 여유 블록
```

- `EVENTS`에 `mark`를 넣으면 화면 위 D-day 카드에 표시됩니다.
- `INFO`의 `range`·`type`을 `''`로 비워두면 "확인 필요"로 강조됩니다.
- `SUBJ`의 `etc`(기타)는 지우지 않습니다.
- `CONFIG.storageKey`는 학기마다 다르게 정합니다. 이전 학기의 체크 기록과 섞이지 않습니다.

> 사용 중에는 공부 블록을 중간에 끼워 넣지 말고 그 날짜의 맨 뒤에 추가하세요. 체크 기록이 날짜 안에서의 순서로 연결됩니다.

## 실행과 배포

- **PC에서 바로 보기**: `index.html`을 브라우저로 엽니다.
- **배포**: 저장소를 Vercel에 연결하면 `git push`할 때마다 자동으로 배포됩니다. 순서는 [배포가이드.md](배포가이드.md)를 참고하세요.

## 데이터 저장

- 체크, 메모, 암기 카드, 타이머 기록은 서버가 아니라 **각 기기의 브라우저**(localStorage)에 저장됩니다.
- 기기 사이에 자동으로 동기화되지 않습니다. `기타` 탭의 백업 기능(링크·파일·코드)으로 직접 옮깁니다.
- 옮길 때는 받는 쪽 내용을 덮어씁니다.
