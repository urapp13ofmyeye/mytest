# 📚 시험 공부 플래너

시험 기간의 일정·공부 계획·체크리스트를 한 화면에서 관리하는 개인용 플래너입니다.
폰과 PC에서 모두 쓸 수 있고, 설치나 로그인 없이 브라우저에서 바로 열립니다.

**로그인하면 내 일정이 내 계정(Supabase)에 저장돼서, 폰과 PC 어디서든 같은 내용을 봅니다.** 과목·시간표·시험·공부 블록은 앱의 `기타 → 내 일정 설정`에서 직접 입력합니다.

## 주요 기능

| 탭 | 할 수 있는 것 |
|---|---|
| ☀️ **오늘** | 시험별 D-day, 시간대별 하루 일정(수업·알바·식사·공부 블록), 할 일 체크와 추가 |
| 📅 **달력** | 월요일 시작 주간 달력, 과목 색으로 구분된 공부 블록, 목록 보기 전환 |
| 📖 **과목** | 전체 개요, 과목별 시험 정보·단계별 전략·진행도·메모 |
| ✅ **체크리스트** | 카테고리별 체크리스트, 카테고리와 항목 직접 추가 |
| ⚙️ **기타** | 교시 기준 고정 시간표, 자격증 D-day, 백업 |

### 공부를 도와주는 기능

- **밀린 일 이월** — 못 끝낸 블록을 모아 보여주고, 오늘·내일로 옮기거나 버릴 수 있습니다.
- **지금 할 일 + 뽀모도로** — 지금 할 블록 하나만 크게 보여주고 25분 타이머로 실제 공부 시간을 기록합니다.
- **AI 프롬프트 복사** — 과목별 시험 유형에 맞춘 퀴즈 프롬프트를 복사해 자료와 함께 붙여넣습니다.
- **암기 카드** — 약어·용어를 넣어두고 답을 가린 채 셀프 테스트합니다. 여러 장을 한 번에 붙여넣을 수 있습니다.
- **확인 필요 표시** — 아직 모르는 시험 범위·유형을 노란색으로 모아 보여줍니다.
- **필수 / 여유 블록** — 밀리면 버려도 되는 블록을 점선으로 구분합니다.

## 폴더 구조

```
index.html                  화면 뼈대 + 로그인 화면
css/style.css               스타일 (다크 모드 포함)
data/defaults.js            빈 일정 틀, 계정의 일정을 화면 코드에 연결하는 applyPlan()
js/
  store.js                  저장 상태, 날짜·시간 도우미, 공부 블록 계산
  cloud.js                  로그인 · Supabase 저장/불러오기 · 기기 간 동기화
  app.js                    탭 전환, 화면 그리기, 클릭·입력 처리
  components/
    now.js                  밀린 일 상자, 지금 할 일 카드, 뽀모도로 타이머
    today.js                오늘 탭
    calendar.js             달력 탭
    subjects.js             과목 탭, AI 프롬프트, 암기 카드
    checklist.js            체크리스트 탭
    more.js                 기타 탭 (계정, 시간표, 자격증, 백업)
    setup.js                내 일정 설정 (과목·시간표·시험·공부 블록 입력)
private/                    (git 제외) 내 개인 일정 원본
```

## 서버 설정 (Supabase)

- 로그인은 이메일 + 비밀번호입니다. Supabase 대시보드 **Authentication → Providers → Email → Confirm email**을 꺼야 가입 즉시 로그인됩니다.
- 데이터는 `planner` 테이블에 사용자당 한 줄(JSON)로 저장되고, 행 보안 정책으로 본인 행만 읽고 쓸 수 있습니다.
- `js/cloud.js`의 `SB_KEY`는 공개용 anon 키입니다. `service_role` 키는 절대 코드에 넣지 마세요.

## 실행과 배포

- 배포: 저장소를 Vercel에 연결하면 `git push`할 때마다 자동으로 배포됩니다. 순서는 [배포가이드.md](배포가이드.md)를 참고하세요.
- 로그인과 서버 저장이 필요해서 `index.html`을 파일로 직접 열면 동작하지 않습니다. 로컬 확인은 `npx serve` 같은 정적 서버로 하세요.

## 데이터 저장

- 체크, 메모, 암기 카드, 타이머 기록, 일정이 모두 계정에 자동 저장됩니다. 이 기기(localStorage)에는 오프라인용 사본이 남습니다.
- 폰에서 바꾸면 PC에서 앱을 다시 열 때 반영됩니다. 두 기기에서 동시에 고치면 마지막에 저장한 쪽이 남습니다.
- 파일 백업은 `기타` 탭에서 할 수 있습니다.
